# 项目立项说明（Project Proposal）

## 项目名称

椰汁健身房会员管理系统（Gym Management System）

## 项目简介

面向中小型健身房的单体 Web 应用，用于管理会员档案、会员卡、私教课程预约等日常业务，替代手工登记/表格管理方式，提升前台接待与会员服务的效率。

## 目标用户

| 用户角色 | 使用诉求 |
| --- | --- |
| 健身房前台/店员 | 快速为新人办卡登记、查询会员信息、处理续费与课程预约 |
| 会员 | 查询自己的会员卡余额/有效期、预约团课与私教课 |
| 店长/管理员 | 统计会员数量、活跃度与营收概况 |

## 优先实现场景（按优先级排序）

1. **会员登记与办卡**：录入会员基本信息（姓名、手机号、性别等），并关联一张会员卡（卡类型、有效期、剩余次数/金额）。
2. **会员卡到期提醒与续费**：查询即将到期的会员卡，支持续费延长有效期。
3. **课程预约**（后续迭代）：会员预约团课/私教课，教练查看当日预约名单。

## 两个核心模型

### 1. Member（会员）

会员的基础档案信息。

- 属性：`id`、`name`（姓名）、`phone`（手机号，唯一）、`gender`（性别）、`birthday`（生日）、`createdAt`（入会时间）
- 关系：一个会员可持有一张或多张会员卡（`Member 1 — N MembershipCard`）

### 2. MembershipCard（会员卡）

会员持有的卡务信息，是收费与入场权限的核心依据。

- 属性：`id`、`cardType`（卡类型：次卡 / 月卡 / 年卡）、`startDate` / `endDate`（有效期）、`remainingTimes`（剩余次数，次卡适用）、`status`（状态：正常 / 过期 / 停用）、`memberId`（所属会员）

## 技术栈（阶段一）

- Java 21 + Spring Boot 4.0.x（单体架构，位于仓库 `monolith/` 目录）
- Maven 构建（`mvnw` 包装器）
- 包名：`com.zjgsu.yz`
